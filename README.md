# RBK Enterprise — Website

Single-page website for RBK Enterprise, an FMCG goods wholesaler in Parappur, Thrissur, Kerala (cold-pressed coconut oil, other edible and non-edible oils, animal feeds, oil cakes and feed mixes).

`index.html` is the whole site in one self-contained file, exported from the Muse web artifact `rbk-enterprise-website`. Content edits are made in the artifact and re-exported; this repository holds the published build.
